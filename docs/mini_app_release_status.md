## Исправление закрытого выпуска 2923f51, 11.10.2026

Текущая рабочая версия main/VPS: 2923f51865e2a08decc2d0d465fa24e62daeed85. Исправление выполнено по сообщению владельца о неработающем «Далее» и пожеланию убрать встречи на 15 минут. Общая аудитория остаётся закрытой двумя аккаунтами.

Причина POST /holds=503: SQLite не мог записать временный журнал savepoint в read_only-контейнере без writable /tmp; на копии воспроизведена disk I/O error. В Compose всех трёх процессов добавлен приватный tmpfs /tmp с пределом 16 МБ, noexec/nosuid/nodev. Корневая файловая система остаётся read_only; схема v11 не менялась. UI прокручивает к новому шагу и ошибке, чтобы сообщение не оставалось выше экрана.

Новые длительности общие для бота/API: Телемост 30/45/60/90 минут, Zoom 30 минут. Сервер отклоняет 15 минут и при прямом запросе старого клиента; история записей сохраняется.

Проверки: целевые Python 31 passed, TypeScript/Vite и frontend 4 passed; полный Linux CI dev успешен ([38165776947](https://github.com/elenalipovik-ctrl/TGbot-for-meeting-planning/actions/runs/38165776947)), дополнительный dev workflow также успешен. Локальный полный запуск не имеет подтверждённого результата из-за ограничения времени инструмента; доказательство полного набора относится к Linux CI. CI main того же SHA запущен, на момент записи ещё выполняется.
