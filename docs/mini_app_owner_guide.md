# Передача Telegram Mini App владельцу

Дата: 11.10.2026. Реализация готова; фактический статус выпуска и ограничений см. mini_app_release_status.md. Исторические журналы не заменяют актуальный статус.

## Как пользоваться

1. Ссылка для участников домашнего задания: https://t.me/MyMeetPlanning_bot. После /start открыть кнопку «Планировщик встреч» в меню чата.
2. Новый посетитель даёт согласие и запрашивает доступ. Уведомление приходит администратору в этот же бот; после допуска посетитель выбирает формат, длительность, дату и время, заполняет контакты и отправляет заявку.
3. Администратор получает заявку через бота, рассматривает её в чате или Mini App, создаёт настоящую ссылку Телемоста/Zoom и добавляет её при подтверждении. Google автоматически создаёт событие и отправляет приглашение на email посетителя. Отдельное подключение Google посетителю не требуется.
4. Статус, подтверждение и отмена приходят через бота. В Mini App есть «Мои заявки» и «Обновить статус заявки».
5. «Назад» возвращает на предыдущий шаг и сохраняет введённые данные. На первом шаге есть «На главную»; на главной внутри Telegram - «Вернуться в чат бота». Закрытие приложения не отменяет отправленную заявку.
6. Администратор сам добавляет/редактирует шаблоны и публикует следующие дни в «Интервалах». Сейчас опубликована неделя 12/13/15/16 октября; автоматического повторения недели нет. Пустая следующая неделя означает отсутствие опубликованного времени, а не поломку.

Рабочие начала: 10:30, 11:30, 13:30, 15:00, 16:30. Среда/суббота/воскресенье закрыты; окончание до 18:00. Доступность учитывает длительность, занятость Google, промежуток между встречами и срок рассмотрения. Длительности 30/45/60/90 минут, Zoom только 30.

## Дополнительная кнопка в профиле

BotFather Main App сейчас выключен (проверено getMe). Для кнопки «Open App» в профиле владелец может выбрать @MyMeetPlanning_bot → Main App, в Enter URL вставить **https://meetcalendar.fin-partner.pro/app/** и Save. Это не требуется для общей кнопки меню чата. Ссылку ?startapp нельзя выдавать как проверенную до включения Main App и фактического открытия.

Не вводить localhost или временный trycloudflare. Ноутбук не нужен для работы: frontend/API/бот/worker находятся на VPS. Поддомен общий; контейнеры bot, worker и api отдельные, данные и правила общие. Переход с главной fin-partner.pro намеренно не добавлен.

## Приёмка и обслуживание

Реальная заявка №2 прошла посетитель → Telegram-уведомление владельцу → подтверждение в боте → Google → email (получение подтверждено владельцем) → отмена общим сервисом/worker → отменённое Google-событие → уведомления обеим ролям. Контрольная встреча освобождена; обычные встречи не затронуты.

Аппаратные проверки всех Android/iOS/Desktop/Web, большого системного шрифта, клавиатуры/safe area и сетевой профиль D-08 не подменяются браузерным тестом. Остаток указан в матрице T-01–T-44. Правовая зависимость исходного MVP перед реальными клиентами остаётся у владельца; учебное открытие не означает юридическое заключение.

Код сохраняется в dev; только проверенная версия программы выпускается через main. Auto-deploy читает main и успешный CI; push в dev сервер не меняет. Секреты только в .env, не отправлять их в чат/GitHub. Резервные копии перед выпусками сохранены на VPS; новое регулярное резервирование в объём не добавлялось.

Восстановление: mini_app_release_runbook.md. При ошибке сначала сохранить диагностику, проверить API/бот/worker, версию и целостность. Не возвращать старую SQLite поверх новых встреч/Google-событий без остановки писателей и сверки внешних изменений. Ограничение Mini App двумя аккаунтами можно вернуть отдельным флагом MINI_APP_RESTRICTED=true без замены данных.
