# Закрытая проверка через существующего бота

Статус 11.10.2026: пользователь согласовал Cloudflare Tunnel и кнопку только своему личному чату @MyMeetPlanning_bot. MA-5 остаётся в работе, выпуск MA-6 не согласован.

## Выполнено

- Отдельный запуск `python -m meeting_bot.owner_preview --env-file .env-miniapp-owner`, 127.0.0.1:8768.
- Реальная подпись Telegram; допускается только BOT_ADMIN_ID. Ограничение проверяется до создания сессии, при каждом обращении, внутри операций записи и для старых сессий.
- Только `.secrets/miniapp-owner/synthetic.sqlite`. Рабочий .env не изменён; в отдельную игнорируемую конфигурацию скопированы только токен и ID владельца.
- Два согласованных шаблона, синтетическая заявка и расписание пн/вт/чт/пт. Начала 10:30, 11:30, 13:30, 15:00, 16:30, окончание до 18:00. При первом запуске создаются интервалы ближайших шести дней; последующие изменения администратора сохраняются.
- Календарь имитируется в памяти. Google-клиент, polling, обработчик доставки уведомлений и email не запускаются. Google-настройки в этом режиме запрещены. Статус Google здесь относится к имитации, не к рабочему подключению.
- Публичный сервер не содержит /local-preview/session; параметр persona не позволяет сменить пользователя. Фронтенд требует настоящий initData и показывает тестовую пометку.
- Cloudflared 2026.10.0 загружен из официального GitHub-релиза Cloudflare. SHA-256 проверен по метаданным релиза. Файл и логи в игнорируемой .secrets/miniapp-owner.
- setChatMenuButton вызван с явным chat_id владельца. Проверены личная кнопка и неизменность общего меню. Предыдущее меню сохранено локально.
- Пройдены проверки API, локальной приёмки, закрытого режима и возврата меню; TypeScript/Vite, четыре теста интерфейса, актуальность OpenAPI и типов. Публичный /app/ отвечает 200, API без сессии 401, маршрут подставного входа 404.

## Что ещё не проверено

Владелец должен открыть кнопку в настоящем Telegram с телефона. Только по результату отмечается вход и мобильный WebView (MA-5-E01). Тестовая база не обменивается заявками с рабочим чат-ботом. Проверка общей рабочей базы, настоящего Google и доставки остаётся отдельным этапом с резервным копированием.

Ссылка работает, пока включены ноутбук, API и туннель. После остановки или сна ноутбука недоступна; новый туннель создаёт новый адрес. Это временная проверка, без автоматического запуска после перезагрузки. HTML доступен публично, персональные и деловые API только владельцу после авторизации. Вводить только вымышленные контакты. Текущий адрес и PID сохранены локально в .secrets/miniapp-owner/runtime.json.

## Вернуть прежнюю личную кнопку

`python -m meeting_bot.owner_preview_menu --env-file .env-miniapp-owner --restore`

Команда восстанавливает меню только владельцу из previous-menu.json. Не задавать эту тестовую кнопку через BotFather /setmenubutton: он меняет общее меню. Старый launcher meeting_bot.api сохраняет запрет рабочего бота; согласованное исключение реализовано отдельным owner-preview.

Источники: [Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/), [Telegram setChatMenuButton](https://core.telegram.org/bots/api#setchatmenubutton).
